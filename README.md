# Night Shift

A calm animated scene: the view from behind an empty chair, looking out through a rainy glass wall at a city at night. A lofi beat plays, made live in the browser.

It's a single HTML file with no libraries, no build step and no audio files. The visuals use canvas and the music uses the Web Audio API.

## Try it

Open `index.html` in a browser and click **Enter the room**.

## Controls

- **Music**: piano, pad, bass and melody
- **Drums**: soft brushed kit
- **Rain**: the rain sound
- **Volume**: overall level

The controls fade away after a few seconds and come back when you move the mouse.
